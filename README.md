# Optimising Delivery ETAs with Graph-Based Network Intelligence

A professional, reproducible machine-learning and network-science capstone for logistics operations.

## What this project delivers
1. **Graph construction and data pipeline** — validates trip segments and converts origin → destination movements into a directed weighted graph.
2. **Hub and corridor audit** — computes betweenness, weighted in/out degree and clustering to identify structural bottlenecks.
3. **Graph-enhanced ETA model** — benchmarks a baseline operational model against a model enriched with graph features.
4. **FL vs Carting decision framework** — transparent rules using distance, dispatch hour and delay risk.
5. **Network Operations Strategy Memo** — top bottlenecks, intervention logic and revenue-at-risk proxy.
6. **Streamlit dashboard** — model comparison, bottleneck hubs, interventions and route-type decision support.

## Quick start
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.pipeline --generate-demo --run-all
streamlit run app/dashboard.py
```

## Architecture
```
Raw trips → validation → directed graph → graph metrics
                               ↓
Operational features → baseline ETA model
Graph features       → enhanced ETA model → benchmark
                               ↓
                       bottleneck ranking
                               ↓
                   interventions + FL/Carting
                               ↓
                        Streamlit dashboard
```

## Reproducibility
The project ships with deterministic synthetic logistics data because proprietary operational trip data is unavailable. The same pipeline accepts a real CSV matching the documented data contract in `src/data.py`.

## Evaluation
The benchmark reports:
- **MAE** in minutes
- **% of trips within ±15% of actual duration**

Metrics are generated by the pipeline and are not hard-coded.
